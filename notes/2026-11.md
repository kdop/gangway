# 2026-11

## 2026-11-19 Design overhaul
*tags: design, blueprint, plan, gate, controller, tailscale, tsnet, go, session-key, folder-grants, safe-commands*

- Kostas restated the idea: Gangway is just-in-time approval of the commands an AI may run on a host. Not a product. The reason is that SSH gives no say over the commands.
- Kostas changed the shape: a controller on Tailscale replaces the public rest-api. The AI calls the controller's API and does not have to be on Tailscale. The session key lives 30 minutes. The web page and Google login are out of the first version.
- Kostas left the product and planning docs to Claude. `blueprint.md` was rewritten, `plan.md` and `README.md` were added. The first draft of the blueprint is in git at `d963186`.
- Calls Claude made that Kostas has not confirmed line by line: the gate lives in the cli-tool, approval in the host terminal, the cli-tool makes the key, the key is tied to the first AI, no root. They are marked in `CLAUDE.md`.
- Kostas added folder grants: the cli-tool names the folders the AI may read, at a later stage, not in the first version. Claude's limit: hard for file reads only, no sandbox for commands yet.
- Kostas added a choice to approve all safe, read-only commands, also at a later stage. Claude's limits: fixed list, no shell, nothing that prints file contents until folder grants exist.
- Kostas agreed to Go for the cli-tool. Claude's calls on top: Tailscale built in with `tsnet`, an ephemeral tagged auth key, the controller in Go too. `tsnet` and auth key facts checked against the Tailscale docs today.
- Kostas said the controller is a web app, a REST API with a dashboard, and left the stack to Claude (not keen on Django). Claude's call: Go, server-made pages with htmx, dashboard on the Tailscale side only.
- Kostas: where the controller listens is a setting (default localhost, can be Tailscale), not a design question. "Always allow" moves to the second stage; the first version asks `y`/`n` every time.
- Kostas: time and size limits on a command, not strict, with a "go on or stop" question past a limit. `login` once, key in a file in the home folder, never given to the AI. Dots on start, then the session key.
- Kostas: Linux hosts only. No open design questions are left; step 1 of `plan.md` can start.
- Kostas asked where the yes/no lives; accepted the cli-tool. Storage settled: plain files on the host, sessions in memory only, no database yet.
- Dropped: signing commands end to end. With the gate on the host, a bad controller can only ask.
