Ephemeral remote access for AI, with just-in-time approval of commands.

build-box: gangway

The AI is asking. You are the gate.

TRY IT  ·  PRESS y OR n

How it works

AI toolAsks the controller to run a command.
→
ControllerPasses each request to the host, then relays the answer back to the AI tool.
→
You: y or nThe cli-tool on the host shows you each command. It runs only if you approve.

Why it is safe to hand over

the gate

On the host, never in the AI

The thing being checked is not the checker. A controller that is taken over can only ask.

the line

You approve what runs

The prompt shows the exact command. A request with a hidden or control character is refused before it reaches you.

the clock

Access ends by itself

A session lasts 30 minutes. Only the person at the terminal can extend it, and no answer means no.

the network

The host is never open

It dials out over Tailscale, which is built into the program. No root, nothing to install.

the key

One key, one AI

The session key works for the first AI that uses it. A copy is of no use to a second caller.

the log

Every session is written down

Each request, your answer and the output go to a file on the host that only you can read.

Get it

Both programs run on the same machine and talk over localhost. Nothing leaves the machine. No Tailscale, no keys.

  1. Install both programs
    curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/kdop/gangway/main/install.sh | sh -s -- all
  2. Start the controller, in terminal 1
    gangway-controller -local
  3. Start a session, in terminal 2
    gangway --local
  4. Send a command. Paste the line it prints to an AI that has the skill. Or send one by hand with curl: the README shows how.

The host is never open to the internet. Tailscale is bundled in both the controller and the CLI: no Tailscale installation needed.

  1. Make two auth keys in the Tailscale admin page. For the controller: reusable, not ephemeral. For the hosts: reusable, ephemeral, with a tag that may reach the controller and nothing else.
  2. On the controller machine, install it, store its key, start it
    curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/kdop/gangway/main/install.sh | sh -s -- controller
    gangway-controller login
    gangway-controller
  3. On each host, install the cli-tool, store the hosts' key, start a session
    curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/kdop/gangway/main/install.sh | sh
    gangway login
    gangway
  4. Paste the line it prints to an AI that has the skill.

Linux, x86_64 or aarch64. No root. Each program is one file in ~/.local/bin.
